# Andrea Longacre-White — v3

Static HTML/CSS comparison with compact borderless services. Caslon header and headings; Messina Sans supporting copy.

Four Messina webfonts are stored in resources/fonts/ and loaded by resources/css/expansion.css. The italic face uses MessinaSans-RegularItalic.woff2.

Section headings briefly display full-screen on hover or activation; reduced-motion preferences disable the effect.

GitHub Pages: main branch, / (root). V2 and the original art site are unchanged.
